#  KANTOR – Fullstack Application

Prosty projekt fullstack (client + server) do obsługi aplikacji kantorowej.

---

# Struktura projektu

```
KANTOR/
├── server/   (backend - Node.js)
└── client/   (frontend - React)
```



---

# Instalacja projektu

## 1. Backend (server)

Przejdź do folderu `server`:

```bash
cd server
```

Zainstaluj zależności:

```bash
npm install
```

---

## 2. Frontend (client)

Przejdź do folderu `client`:

```bash
cd ../client
```

Zainstaluj zależności:

```bash
npm install
```

---

# Uruchamianie projektu

## Backend (server)

W folderze `server` uruchom:

```bash
node app.js
```

Domyślnie backend działa na:

```
http://localhost:3000
```

---

## Frontend (client)

W folderze `client` uruchom:

```bash
npm run dev
```

Frontend uruchomi się domyślnie na:

```
http://localhost:5173
```

---


---

# Kolejność uruchamiania

1. `cd server`
2. `npm install`
3. `node app.js`
4. nowy terminal → `cd client`
5. `npm install`
6. `npm run dev`
